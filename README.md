# Bileton — маркетингтік веб-сайт (1-кезең)

Автобус билеттерін іздеу платформасы Bileton-ның басты беті. Толық техникалық
тапсырма `bileton-web-tz.md` файлында сипатталған (жеке сақталады, бұл
репозиторийге кірмейді).

## Стек

Бір `index.html` файлы, барлық CSS пен JS соның ішінде (CLAUDE.md
талабы бойынша). Сыртқы тәуелділіктер тек CDN арқылы:

- Tailwind CSS (Play CDN, runtime JIT)
- Google Fonts: Montserrat (тақырыптар) + Golos Text (негізгі мәтін) +
  Noto Sans SC (тек қытай тілі таңдалғанда жүктеледі)
- Phosphor Icons (веб-қаріп)
- Simple Icons (App Store / Google Play белгішелері)

Build қадамы жоқ. `npm install` тек скриншот құралына арналған Puppeteer-ды
орнатады.

## Іске қосу

```bash
npm install          # Puppeteer орнату (скриншот үшін)
npm run serve         # http://localhost:3000 адресінде сервер көтеру
```

Скриншот түсіру (`CLAUDE.md`-дегі жұмыс тәртібі бойынша):

```bash
node screenshot.mjs http://localhost:3000            # десктоп, толық бет
node screenshot.mjs http://localhost:3000 label --mobile
```

Скриншоттар `./temporary screenshots/` қалтасына сақталады (git-ке кірмейді).

## Құрылым

```
index.html          Сайттың өзі (жалғыз файл)
assets/img/          Оңтайландырылған суреттер (JPG + WebP), логотип, favicon
Photo/                Пайдаланушы берген түпнұсқа фотолар
serve.mjs            Локальді статикалық сервер
screenshot.mjs        Puppeteer скриншот құралы
CLAUDE.md            Жобаның frontend ережелері
```

## Тіл жүйесі

Алты тіл: орысша (әдепкі), қазақша, өзбекше, қырғызша, қытайша, ағылшынша.
Барлық мәтін `index.html` ішіндегі `<script>` блогында, `T` объектісінде
тұрады (`data-i18n`, `data-i18n-placeholder`, `data-i18n-aria` атрибуттары
арқылы қолданылады). Тіл браузер баптауы бойынша автоматты анықталады,
`localStorage`-те сақталады, әдепкісінде орысша ашылады.

## 1-кезең шектеулері (әдейі)

Бұлар кейін ауыстырылуы тиіс, техникалық тапсырмада да, пайдаланушы
хабарламасында да атап өтілген:

- **App Store / Google Play сілтемелері** — қазір `href="#"`, нақты
  қосымша дайын болған соң ауыстыру керек.
- **QR-кодтар** — `placehold.co` арқылы уақытша орын толтырғыш,
  нақты QR-мен ауыстырылады.
- **Серіктестер логотиптері** — нақты SVG/PNG логотип болмағандықтан,
  инициалдардан жасалған градиентті белгі қолданылды.
- **Қала автотолтыру және танымал бағыттар** — backend endpoint-тері
  әлі жоқ болғандықтан (`bileton-web-tz.md` 9.4-бөлімі), қолмен
  жазылған тізім қолданылды. Backend дайын болған соң
  `GET /api/v1/cities/popular` және `GET /api/v1/routes/popular`
  сұраныстарына ауыстыру керек.
- **Іздеу формасы** — басылғанда қосымшаны жүктеуге шақыратын
  модаль ашады (2-кезеңде `/search` бетіне бағытталады, ешбір
  компонент қайта жазылмайды, ТЗ-ның негізгі қағидасы осы).
- **/carriers, /faq, /about, /terms, /privacy, /contacts** беттері
  бұл кезеңде жасалған жоқ, тек басты бет. Навигациядағы сілтемелер
  қазірше сол беттегі тиісті бөлімге апарады.

## Ескерту

Жоба қалтасында `SKILL.md`, `plugin.json`, `core.py`, `design_system.py`,
`search.py` сияқты файлдар бар — бұлар кездейсоқ осы қалтаға түсіп қалған
Claude Code-тың `frontend-design` / `ui-ux-pro-max` скилл пакетінің ішкі
файлдары, сайт коды емес. Олар `.gitignore`-де сүзілген (репозиторийге
кірмейді), бірақ қалауыңыз болса қалтадан толық өшіруге болады.
