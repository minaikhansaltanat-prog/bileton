# bileton.kz серверге орналастыру

Бұл қалтада PS.kz VPS-іне сайтты шығаруға дайын конфигурация тұр:

- `nginx-bileton.conf` — bileton.kz және www.bileton.kz үшін nginx сервер блогы.
- `deploy.sh` — жобаны rsync арқылы серверге көшіретін скрипт.

## Маған керек ақпарат (дайын болған соң жазыңыз)

1. **Сервер IP мекенжайы** (мысалы 185.xxx.xxx.xxx).
2. **SSH пайдаланушысы** (әдетте `root`, кейде PS.kz өз атауын береді).
3. **Кіру тәсілі**: құпия сөз бе, әлде SSH кілт (private key) бе. Кілт болса,
   файлды қауіпсіз тәсілмен жіберіңіз.
4. **SSH порты**, әдепкісі 22, PS.kz кейде өзгертіп қоюы мүмкін.
5. **root/sudo құқығы бар ма** — nginx бен certbot орнату үшін керек.
6. **Домен DNS жазбасы**: bileton.kz (және www.bileton.kz) A-жазбасы осы VPS
   IP-ге бағытталған ба, әлі бапталмаған ба. Бапталмаса, PS.kz домен
   басқару панелінде A-жазбаны сол IP-ге қоямыз.
7. Серверде **nginx мен certbot орнатылған ба**, жоқ па (болмаса мен
   орнатамын, `apt install nginx certbot python3-certbot-nginx` деген
   сияқты, серверіңіздің OS-іне қарай).

## Мен не істеймін (деректер келген соң)

1. SSH арқылы серверге қосыламын, керек болса nginx/certbot орнатамын.
2. `deploy.sh` арқылы сайт файлдарын `/var/www/bileton` қалтасына көшіремін.
3. `nginx-bileton.conf`-ты серверге қойып, іске қосамын.
4. DNS дұрыс бағытталған соң, `certbot --nginx -d bileton.kz -d www.bileton.kz`
   арқылы тегін SSL сертификат аламын (TZ-дың 10-бөлімінде талап етілгендей).
5. `https://bileton.kz` ашылып тұрғанын тексеремін, скриншотпен растаймын.

## Ескерту

Бұл 1-кезең, яғни тек статикалық `index.html` + суреттер жүктеледі,
backend (api.bileton.kz) бөлек серверде/жолда болуы мүмкін, оған қатысты
ештеңе бұл скрипт өзгертпейді.
